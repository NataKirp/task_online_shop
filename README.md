# task_online_shop

Учебный веб-проект на Django, созданный в рамках изучения темы *«Разработка веб-приложений на Django»*. Проект
представляет собой базовую структуру веб-приложения для магазина цифровых товаров (плагинов, скриптов и утилит).

---

## 🛠️ Технологический стек

* **Backend:** Python 3, Django
* **Frontend:** HTML5, Bootstrap 5

---

## 📂 Структура и архитектура проекта

### 1. Архитектура URL-маршрутизации

Проект использует двухуровневую структуру маршрутизации (разделение на глобальные URL проекта и локальные URL
приложения) с поддержкой пространств имен (`namespace`):

* **Проект (`config/urls.py`):**
    * `/admin/` — стандартная административная панель Django.
    * `/` — подключение изолированных маршрутов приложения `catalog` с пространством имен `catalog`.

* **Приложение (`catalog/urls.py`):**
    * `''` (имя: `home`) — главная страница каталога.
    * `'contacts/'` (имя: `contacts`) — страница с контактной информацией и формой обратной связи.

### 2. Контроллеры (views.py)

Логика обработки запросов реализована на функциях:

* `home(request)` — рендерит главную страницу каталога.
* `contacts(request)` — обрабатывает два типа запросов:
    * `GET` — отображает страницу контактов с формой.
    * `POST` — принимает данные из формы (Имя, Телефон, Сообщение), валидирует наличие CSRF-токена, выводит полученные
      данные в консоль сервера для отладки и возвращает простой `HttpResponse` с благодарностью.

### 3. Шаблонизация (HTML)

Интерфейс построен на базе Bootstrap 5. В проекте используются два основных шаблона:

* `home.html` (Главная страница) — содержит карточную сетку для демонстрации товаров (например, сервис рассылок),
  навигационную панель и подвал сайта с категориями.
* `contacts.html` (Страница контактов) — содержит таблицу с реквизитами организации (Страна, ИНН, Адрес) и POST-форму
  для отправки обратной связи. Форма защищена встроенным тегом `{% csrf_token %}`.

## 🚀 Как запустить проект

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/NataKirp/task_online_shop
   cd  task_online_shop
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python -m venv venv
   # Для Windows:
   venv\Scripts\activate
   # Для macOS/Linux:
   source venv/bin/activate
   ```

3. **Установите Django:**
   ```bash
   pip install django
   ```

4. **Выполните миграции базы данных:**
   ```bash
   python manage.py migrate
   ```

5. **Запустите локальный сервер разработки:**
   ```bash
   python manage.py runserver
   ```

6. **Откройте проект в браузере:**
   Перейдите по адресу [http://127.0.0](http://127.0.0)
